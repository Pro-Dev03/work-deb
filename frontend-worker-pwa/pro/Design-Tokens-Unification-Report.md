# تقرير توحيد المكونات مع نظام التصميم

راجعت المكونات التسعة المرفوعة، وطابقتها كلها على نفس نظام الألوان والمسافات الموجود في `DESIGN_SYSTEM.md`. الملخص أدناه، والملفات الجاهزة للاستخدام مرفقة.

---

## الاكتشاف الأساسي: 3 أنظمة تسمية مختلفة كانت تعمل بالتوازي

عند فحص الملفات التسعة، تبيّن أنها لم تكن كلها تتحدث "لغة" واحدة:

| المجموعة | الملفات | المشكلة |
|---|---|---|
| **أ — قريبة لكن غير مطابقة** | `TaskCard`, `GeofenceRing`, `PhotoUpload`, `MapPicker`, `GeolocationCheck` | تستخدم أسماء متغيرات قديمة شبيهة بالمعنى لكن مختلفة بالاسم: `--line` بدل `--border`, `--ink-soft` بدل `--text-secondary`, `--brand` بدل `--primary-500`, `--signal-in/out` بدل `--success/error-500`, `--gold` بدل `--warning-500` |
| **ب — ألوان مكتوبة يدويًا (Hex)** | `PWAInstallButton`, `PullToRefresh`, `LanguageSwitcher`, `SwipeNav` | لا تستخدم أي متغيرات إطلاقًا — ألوان مباشرة من هوية بصرية قديمة مختلفة تمامًا: أزرق كحلي `#1E3A5F` وأخضر مزرق `#1F6F5C`، لا علاقة لهما بالبنفسجي-النيلي (`#6366F1`) المعتمد الآن |
| **ج — إيموجي بدل أيقونات** | `PWAInstallButton` (📱 ⎋ ➕ ✕), `LanguageSwitcher` (🇸🇦 🇮🇱 🇬🇧) | نظام التصميم ينص صراحة: **"NO Emojis"** — واستخدام أعلام الدول لتمثيل اللغة غير دقيق أصلًا (العربية والعبرية ليستا مرتبطتين بدولة واحدة) |

## اكتشاف إضافي: كلاسات مفقودة

عدة مكونات تستخدم كلاسات مثل `.badge`, `.btn`, `.btn--ghost`, `.btn--sm`, `.btn--block` في القالب (template) **دون تعريفها محليًا** — أي أنها كانت تعتمد على ملف عام (global stylesheet) غير موجود ضمن الملفات المرفوعة. أنشأت `base.css` ليكون هذا الملف المرجعي الرسمي، بدل أن يبقى كل مطور يخترعه من جديد.

---

## الملفات المُسلَّمة

### 1. `tokens.css` — جديد
مصدر واحد لكل متغيرات الألوان/المسافات/الخطوط/الظلال، مطابق حرفيًا لـ `DESIGN_SYSTEM.md`، بما فيه طبقة الوضع الليلي.

### 2. `base.css` — جديد
تعريف الكلاسات المشتركة الناقصة: `.btn` بمتغيراته (`--primary`, `--secondary`, `--ghost`, `--sm`, `--block`) و`.badge` بمتغيراته الدلالية (`success`, `warning`, `error`, `info`, `neutral`).

### 3–9. المكونات السبعة المعاد توحيدها
كل ملف يحمل نفس الاسم الأصلي، وسلوكه (المنطق/الـ props/الأحداث) لم يتغير — فقط طبقة الألوان استُبدلت بالكامل:

| الملف | أهم تغيير |
|---|---|
| `TaskCard.vue` | `--gold/--in/--out` → أعيدت تسميتها `badge-warning/success/error` لتطابق بقية شارات الحالة في التطبيق |
| `GeofenceRing.vue` | `--line/--ink/--signal-*` → `--border/--text-primary/--success-500/--error-500` |
| `PhotoUpload.vue` | إضافة حالة hover بلون العلامة التجارية الفعلي بدل الرمادي العام |
| `MapPicker.vue` | تدرّج الخريطة الأخضر (`#EAF1EC`) — وهو لون من هوية غير هذه — استُبدل بـ `--primary-50/100` |
| `GeolocationCheck.vue` | `--ink-soft/--signal-*` → التوكنز الحالية |
| `SwipeNav.vue` | مؤشرات السحب (`#E2E8F0/#1E3A5F/#4A6FA5`) → `--border-strong/--primary-500/--primary-400` |
| `PullToRefresh.vue` | لون السحب `#1E3A5F` (كحلي قديم) → `--primary-600` |
| `LanguageSwitcher.vue` | حذف أعلام الإيموجي بالكامل، الألوان المكتوبة يدويًا → توكنز، الشكل الآن مطابق لمنتقي اللغة في صفحتي الدخول والملف الشخصي |
| `PWAInstallButton.vue` | حذف كل الإيموجي (📱 ⎋ ➕ ✕) واستبدالها بأيقونات SVG بنفس أسلوب باقي التطبيق، ولون التركواز الأخضر القديم → تدرّج البنفسجي-النيلي الرسمي |

## خطوة تلقائية موصى بها

في نقطة تحميل التطبيق (`main.js` أو `App.vue`)، تأكد من استيراد الملفين بهذا الترتيب قبل أي CSS آخر:

```js
import './tokens.css'
import './base.css'
```

بهذا الشكل، أي مكوّن جديد يُبنى مستقبلًا سيرث نفس اللغة البصرية تلقائيًا دون الحاجة لإعادة اختراع الألوان في كل مرة — وهي بالضبط المشكلة التي كانت موجودة في الملفات التسعة الأصلية.
