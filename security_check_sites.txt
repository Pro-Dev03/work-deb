                        مواقع فحص الأمان الأونلاين
================================================================================

مواقع فحص الأمان الشاملة:
================================================================================

1. OWASP ZAP (Zed Attack Proxy)
   https://www.zaproxy.org/
   - مجاني ومفتوح المصدر
   - فحص شامل للثغرات الأمنية
   - يدعم الأتمتة والفحص اليدوي

2. Burp Suite Community Edition
   https://portswigger.net/burp/communitydownload
   - أداة احترافية لفحص أمان تطبيقات الويب
   - نسخة مجانية متاحة
   - فحص تلقائي ويدوي

3. SSL Labs (SSL/TLS Security)
   https://www.ssllabs.com/ssltest/
   - فحص شهادات SSL/TLS
   - تقييم من A+ إلى F
   - فحص مجاني وسريع

4. Security Headers
   https://securityheaders.com/
   - فحص رؤوس الأمان HTTP
   - تقييم تطبيق أفضل الممارسات
   - مجاني

5. Mozilla Observatory
   https://observatory.mozilla.org/
   - فحص إعدادات الأمان الشاملة
   - تقييم من 0 إلى 100+
   - مجاني من Mozilla

6. Nmap (Network Mapper)
   https://nmap.org/
   - فحص المنافذ والخدمات
   - كشف الثغرات في الشبكة
   - مجاني ومفتوح المصدر

7. VirusTotal
   https://www.virustotal.com/
   - فحص الملفات والروابط
   - كشف البرمجيات الخبيثة
   - مجاني

8. Sucuri SiteCheck
   https://sitecheck.sucuri.net/
   - فحص الموقع من البرمجيات الخبيثة
   - فحص تعطل الموقع
   - مجاني


مواقع فحص API وBackend:
================================================================================

9. Postman Security Tests
   https://www.postman.com/
   - فحص API endpoints
   - اختبار المصادقة والتفويض
   - نسخة مجانية متاحة

10. OWASP API Security Top 10
    https://owasp.org/www-project-api-security/
    - قائمة بالتهديدات الأمنية الشائعة في APIs
    - إرشادات للحماية


مواقع فحص تطبيقات الموبايل:
================================================================================

11. MobSF (Mobile Security Framework)
    https://github.com/MobSF/Mobile-Security-Framework-MobSF
    - فحص تطبيقات Android و iOS
    - تحليل ثابت ودينامي
    - مجاني ومفتوح المصدر


مواقع فحص الكود:
================================================================================

12. SonarQube
    https://www.sonarqube.org/
    - فحص جودة الكود والأمان
    - كشف الثغرات الشائعة
    - نسخة مجانية متاحة (Community Edition)

13. CodeQL (GitHub)
    https://codeql.github.com/
    - فحص ثغرات الأمان في الكود
    - مجاني للمشاريع مفتوحة المصدر
    - متكامل مع GitHub


مواقع فحص الأداء:
================================================================================

14. Webhint - تحليل الأداء والأمان
    https://webhint.io/
    - أدخل رابط موقعك
    - فحص الأداء والأمان وسهولة الوصول
    - من Microsoft

15. GTmetrix - فحص الأداء
    https://gtmetrix.com/
    - أدخل رابط موقعك
    - فحص سرعة التحميل والأداء
    - يقدم نصائح للتحسين

16. PageSpeed Insights - فحص جوجل
    https://pagespeed.web.dev/
    - أدخل رابط موقعك
    - فحص من Google
    - يركز على الأداء وتجربة المستخدم


مواقع فحص HTTPS/TLS:
================================================================================

17. CheckTLS - فحص تكوين TLS
    https://checktls.com/
    - أدخل رابط موقعك
    - فحص تكوين TLS/SSL
    - يكتشف المشاكل في التشفير

18. HSTS Preload - فحص HSTS
    https://hstspreload.org/
    - أدخل رابط موقعك
    - فحص إعدادات HSTS
    - يساعد في تحسين الأمان

ملاحظات مهمة:
================================================================================

- تأكد من أخذ نسخة احتياطية قبل الفحص
- بعض الأدوات تتطلب الوصول إلى النظام المباشر
- فحص الأمان لا يضمن الحماية 100% ولكنه يساعد في اكتشاف المشاكل الشائعة
- قم بإصلاح المشاكل المكتشفة بالترتيب حسب الخطورة
- راجع النتائج دورياً للحفاظ على مستوى أمان عالي
