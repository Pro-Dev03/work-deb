1. نظرة عامة
================================================================================

🔹 ما هو WAHA؟
-----------------
WAHA = WhatsApp HTTP API

هو خدمة مفتوحة المصدر توفر واجهة HTTP REST لإرسال واستقبال رسائل 
واتساب من سيرفرك الخاص، بدون رسوم لكل رسالة.

🔹 المطور:
-----------
- devlikeapro (devlike.pro)
- ترخيص: Apache 2.0
- مفتوح المصدر 100%

🔹 المواقع الرسمية:
--------------------
- الموقع الرئيسي: https://waha.devlike.pro/
- التوثيق: https://waha.devlike.pro/docs/
- GitHub: https://github.com/devlikeapro/waha
- Dashboard: https://waha.devlike.pro/dashboard
- Swagger: https://waha.devlike.pro/swagger

2. كيف يعمل WAHA
================================================================================

🏗️ البنية المعمارية:
--------------------

┌─────────────────────────────────┐
│   تطبيقك (WorkTrack Backend)     │
│   - يستدعي HTTP API             │
│   - يرسل ويستقبل رسائل          │
└──────────────┬──────────────────┘
               │ HTTP Requests
               ↓
┌─────────────────────────────────┐
│   WAHA (Docker Container)       │
│   - يربط جلسات واتساب          │
│   - يوفر REST API               │
│   - يرسل Webhooks               │
└──────────────┬──────────────────┘
               │ WhatsApp Protocol
               ↓
┌─────────────────────────────────┐
│   واتساب (الجلسة المرتبطة)     │
│   - رقم هاتفك                   │
│   - يرسل ويستقبل رسائل         │
└─────────────────────────────────┘

🔹 المفهوم الأساسي:
------------------
1. تقوم بتشغيل حاوية Docker على سيرفرك
2. تربط جلسة واتساب عبر QR Code (مثل web.whatsapp.com)
3. تستخدم HTTP API لإرسال واستقبال الرسائل
4. WAHA يتعامل مع بروتوكول واتساب بدلاً منك

🔹 المحركات المتاحة (Engines):
-------------------------------
- WEBJS (الافتراضي): يستخدم Chromium - ميزات كاملة
- NOWEB: WebSocket Node.js - أخف وزناً
- GOWS: WebSocket Golang - أداء عالي

3. خطوات التثبيت والإعداد
================================================================================

📦 المتطلبات:
------------
الشيء الوحيد المطلوب: Docker

🔧 خطوات التثبيت:
----------------

الخطوة 1: تثبيت Docker
-----------------------
# Linux
sudo apt install docker.io

# Windows/Mac
# قم بتحميل Docker Desktop من الموقع الرسمي

الخطوة 2: تحميل صورة WAHA
---------------------------
docker pull devlikeapro/waha

الخطوة 3: إعداد بيانات الاعتماد
---------------------------------
docker run --rm -v "$(pwd)":/app/env devlikeapro/waha init-waha /app/env

سيتم إنشاء ملف .env يحتوي على:
- Username: admin
- Password: 11111111111111111111111111111111
- API Key: 00000000000000000000000000000000

الخطوة 4: تشغيل WAHA
--------------------
docker run -it --env-file "$(pwd)/.env \
  -v "$(pwd)/sessions:/app/.sessions" \
  --rm -p 3000:3000 \
  --name waha devlikeapro/waha

النتيجة: السيرفر يعمل على http://localhost:3000

الخطوة 5: فتح لوحة التحكم
--------------------------
افتح المتصفح على: http://localhost:3000/dashboard

1. سجل الدخول بـ: admin / 11111111111111111111111111111111
2. اتصل بالسيرفر باستخدام الـ API Key من ملف .env

الخطوة 6: إنشاء جلسة جديدة (QR Code)
--------------------------------------
1. اضغط على "New Session" في Dashboard
2. سيظهر QR Code
3. افتح واتساب على هاتفك
4. اذهب إلى Settings > Linked Devices > Link a Device
5. امسح الكود
6. سيتم ربط رقم واتسابك بالسيرفر

الخطوة 7: إرسال أول رسالة
--------------------------
curl -X POST http://localhost:3000/api/sendText \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_API_KEY" \
  -d '{
    "session": "default",
    "chatId": "962790000000@c.us",
    "text": "مرحباً! هذه رسالة تجريبية من WAHA"
  }'

1. إشعار بدء الدوام (Check-in)

4. تعيين مهمة جديدة

   الموقع: برج الأمل
   الموعد: اليوم 10:00

5. تذكير بمواعيد المهام
   ⏰ تذكير: لديك مهمة في 30 دقيقة
   المهمة: فحص دوري

🔧 التكامل مع Backend:
----------------------

إضافة إلى ملف Go handlers:

```go
type WhatsAppService struct {
    wahaURL    string
    apiKey    string
    session   string
}

func NewWhatsAppService() *WhatsAppService {
    return &WhatsAppService{
        wahaURL:  "http://localhost:3000",
        apiKey:  os.Getenv("WAHA_API_KEY"),
        session: "default",
    }
}
```

6. أمثلة برمجية

📝 مثال 1: إرسال رسالة نصية بسيطة
--------------------------------------
```go
func (w *WhatsAppService) SendSimpleMessage(phoneNumber, message string) error {
    chatId := phoneNumber + "@c.us"
    
    payload := map[string]interface{}{
        "session": w.session,
        "chatId":  chatId,
        "text":    message,
    }
    
    jsonData, _ := json.Marshal(payload)
    
    req, _ := http.NewRequest("POST", 
        w.wahaURL + "/api/sendText", 
        bytes.NewBuffer(jsonData))
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("X-Api-Key", w.apiKey)
    
    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        return err
    }
    defer resp.Body.Close()
    
    return nil
}
```

```go
// في Backend - استقبال رسائل من الموظفين
func (h *WhatsAppHandler) HandleIncomingMessage(c *gin.Context) {
    var message struct {
        Session string `json:"session"`
        From    string `json:"from"`
        Text    string `json:"text"`
        Timestamp int64 `json:"timestamp"`
    }
    
    if err := c.ShouldBindJSON(&message); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{"error": err.Error()})
        return
    }
    
    // معالجة الرسالة
    log.Printf("رسالة من %s: %s", message.From, message.Text)
    
    // يمكن إضافة منطق لمعالجة أوامر معينة
    // مثال: إذا أرسل الموظف "حالتي" يرد عليه بمعلومات حالته
    
    c.JSON(http.StatusOK, gin.H{"status": "received"})
}
```

7. الخلاصة والتوصيات
================================================================================

📊 ملخص:
--------
✅ WAHA هو حل ممتاز للمشاريع الصغيرة والمتوسطة
✅ مناسب جداً لمشروع WorkTrack لإرسال إشعارات الموظفين
✅ مجاني تماماً بدون تكاليف إضافية
✅ سهل التثبيت والإدارة

🎯 التوصيات لمشروع WorkTrack:
---------------------------------

1. ✅ استخدم WAHA للإشعارات التلقائية:
   - بدء/إنهاء الدوام
   - تنبيهات النطاق الجغرافي
   - تعيين المهام

2. ✅ استخدم محرك NOWEB:
   - أخف وزناً من WEBJS
   - مناسب للسيرفرات ذات الموارد المحدودة

3. ✅ إعداد جلسة منفصلة للإنتاج:
   - لا تستخدم نفس الجلسة للاختبار والإنتاج
   - استخدم رقم واتساب عمل خاص

4. ✅ إضافة معالجة الأخطاء:
   - إعادة المحاولة في حالة الفشل
   - تسجيل الأخطاء للمراجعة

5. ✅ مراقبة استقرار الخدمة:
   - تأكد من أن الحاوية تعمل دائماً
   - استخدم docker-compose لإدارة الخدمة

⚠️ ملاحظات مهمة:
------------------
1. ⚠️ احفظ ملف .env بأمان - يحتوي على بيانات حساسة
2. ⚠️ استخدم جلسة واتساب مخصصة للعمل - ليس رقمك الشخصي
3. ⚠️ راقب استهلاك الموارد - WAHA قد يكون ثقيلاً
4. ⚠️ تأكد من اتصال الهاتف بالإنترنت دائماً
5. ⚠️ احترم سياسات واتساب - لا ترسل رسائل مزعجة
