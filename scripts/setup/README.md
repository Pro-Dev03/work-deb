# سكربت إدارة المستخدمين - WorkTrack

## الوصف
سكربت bash لإدارة مستخدمي WorkTrack عبر API الباك إند.

## المتطلبات
- curl
- jq (اختياري - لتنسيق JSON)
- الباك إند يعمل على https://worktrack-v2.onrender.com

## الإعداد

### 1. إعداد الباك إند
أضف متغير البيئة التالي في ملف `backend/.env`:
```
ADMIN_SCRIPT_API_KEY=your-secure-api-key-here
```

### 2. إعداد السكربت
أضف المتغيرات التالية في ملف `.env` أو `backend/.env`:
```
API_URL=http://localhost:8080/api/v1
ADMIN_SCRIPT_API_KEY=your-secure-api-key-here
```

## الاستخدام

شغل السكربت:
```bash
./scripts/setup/change_credentials.sh
```

## الوظائف المتاحة

1. **عرض جميع المستخدمين** - يعرض قائمة بجميع المستخدمين في النظام
2. **تغيير إيميل مستخدم** - تغيير إيميل مستخدم موجود (باستخدام ID أو الإيميل الحالي)
3. **تغيير كلمة مرور مستخدم** - تغيير كلمة مرور مستخدم موجود
4. **إنشاء حساب أدمن جديد** - إنشاء حساب مدير جديد
5. **حذف حساب** - حذف مستخدم من النظام (مع تأكيد)

## API Endpoints

السكربت يستخدم الـ API endpoints التالية:

- `GET /api/v1/admin-script/users` - عرض جميع المستخدمين
- `PUT /api/v1/admin-script/users/email` - تغيير إيميل مستخدم
- `PUT /api/v1/admin-script/users/password` - تغيير كلمة مرور مستخدم
- `POST /api/v1/admin-script/users/admin` - إنشاء حساب أدمن جديد
- `DELETE /api/v1/admin-script/users` - حذف مستخدم

## الأمان

- السكربت يستخدم API key للمصادقة
- يفضل تغيير الـ API key الافتراضي في الإنتاج
- يتم تشفير كلمات المرور قبل إرسالها للباك إند
- جميع العمليات تتطلب تأكيد من المستخدم

## التشغيل على خادم الإنتاج

في الإنتاج، تأكد من:
1. تغيير ADMIN_SCRIPT_API_KEY إلى قيمة قوية
2. استخدام HTTPS للاتصال بالباك إند
3. تقييد الوصول للسكربت على المستخدمين المصرح لهم فقط
